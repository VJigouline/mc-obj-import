# Wavefront OBJ test files

Real Wavefront OBJ files that the tests load. They are unchanged copies, taken at commit `1d3772857e` of three.js.

| Files | What they cover | Source and licence |
| --- | --- | --- |
| `tree.obj` | A tree, without materials | The [three.js](https://github.com/mrdoob/three.js) repository (`examples/models/obj`), under its [MIT licence](https://github.com/mrdoob/three.js/blob/dev/LICENSE); no other licence is stated for it. |

The material and texture tests use a small model written in the tests.

These files keep their own licences. They are test data only, and are not part of the npm package, which includes only `dist`, `Documentation`, `README.md` and `LICENSE`.
